## Workflows

A workflow is an automation you build in Lodol. Through the API you can list the workflows in your workspace and read a single one, including its full program. Runs live under [Executions](/docs/api-reference/executions).

### The workflow object

```json
{
  "id": "665f1a2b3c4d5e6f7a8b9c0d",
  "name": "Welcome Email Workflow",
  "description": "Sends a welcome email when a user signs up",
  "created_by": "665f1a2b3c4d5e6f7a8b9c0e",
  "created_at": "2026-01-15T10:30:00+00:00",
  "updated_at": "2026-01-15T10:30:00+00:00",
  "last_run_at": "2026-03-17T08:00:00+00:00",
  "publish_state": "published"
}
```

| Field | Type | Description |
| --- | --- | --- |
| `id` | string | Unique identifier (a MongoDB ObjectId) |
| `name` | string | The workflow's name |
| `description` | string | The workflow's description |
| `created_by` | string \| null | ID of the user who created it |
| `created_at` | string \| null | ISO 8601 creation timestamp |
| `updated_at` | string \| null | ISO 8601 timestamp of the last edit |
| `last_run_at` | string \| null | ISO 8601 timestamp of the most recent run |
| `publish_state` | string | Whether the workflow is `published` |

---

### List workflows

```
GET /api/v1/workflows
```

Returns the workflows in the workspace tied to your API key. The workspace comes from the key, so there is no `team_id` parameter.

**Required scope:** `workflows:read`

<Tabs items={['cURL', 'Python']}>

```bash tab="cURL"
curl https://api-prod.lodol.com/api/v1/workflows \
  -H "Authorization: Bearer sk_live_..."
```

```python tab="Python"
workflows = client.workflows.list()

for workflow in workflows:
    print(workflow.id, workflow.name)
```

</Tabs>

**Response (200)**

```json
{
  "workflows": [
    {
      "id": "665f1a2b3c4d5e6f7a8b9c0d",
      "name": "Welcome Email Workflow",
      "description": "Sends a welcome email when a user signs up",
      "created_by": "665f1a2b3c4d5e6f7a8b9c0e",
      "created_at": "2026-01-15T10:30:00+00:00",
      "updated_at": "2026-01-15T10:30:00+00:00",
      "last_run_at": "2026-03-17T08:00:00+00:00",
      "publish_state": "published"
    }
  ]
}
```

### Get a workflow

```
GET /api/v1/workflows/:id
```

Reads a single workflow by ID. The response adds a `program` field with the full workflow definition.

**Required scope:** `workflows:read`

<Tabs items={['cURL', 'Python']}>

```bash tab="cURL"
curl https://api-prod.lodol.com/api/v1/workflows/665f1a2b3c4d5e6f7a8b9c0d \
  -H "Authorization: Bearer sk_live_..."
```

```python tab="Python"
workflow = client.workflows.retrieve("665f1a2b3c4d5e6f7a8b9c0d")

print(workflow.name)
print(workflow.program)
```

</Tabs>

**Response (200)**

```json
{
  "id": "665f1a2b3c4d5e6f7a8b9c0d",
  "name": "Welcome Email Workflow",
  "description": "Sends a welcome email when a user signs up",
  "program": {
    "kind": "Program",
    "version": 1,
    "body": []
  },
  "created_by": "665f1a2b3c4d5e6f7a8b9c0e",
  "created_at": "2026-01-15T10:30:00+00:00",
  "updated_at": "2026-01-15T10:30:00+00:00",
  "last_run_at": "2026-03-17T08:00:00+00:00",
  "publish_state": "published"
}
```

The `program` field holds the full workflow definition. See the [Core](/docs/api-reference/core) section for the expressions and statements it is made of.
