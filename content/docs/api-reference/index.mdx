## API Reference

The Developer API is REST over HTTPS with JSON request and response bodies. Every endpoint lives under one base URL:

```
https://api-prod.lodol.com/api/v1
```

### Requests

Send your API key as a bearer token. Requests with a body use `Content-Type: application/json`. The workspace is taken from the key, so you never pass an account or team ID.

```bash
curl https://api-prod.lodol.com/api/v1/workflows \
  -H "Authorization: Bearer sk_live_..."
```

The [Python SDK](https://github.com/LodolAI/lodol-python) wraps every endpoint below. Install it with `pip install lodol` and it sets these headers for you.

### Pagination

List endpoints return newest first and page with a cursor. Pass `limit` to size the page and `after` to continue from where you left off.

| Parameter | Type | Description |
| --- | --- | --- |
| `limit` | integer | Results per page, 1 to 100 (default 20) |
| `after` | string | Cursor: the ID of the last item on the previous page |

```bash
# First page
curl "https://api-prod.lodol.com/api/v1/executions?limit=20" \
  -H "Authorization: Bearer sk_live_..."

# Next page, starting after the last ID you saw
curl "https://api-prod.lodol.com/api/v1/executions?limit=20&after=683b2c3d4e5f6a7b8c9d0e1f" \
  -H "Authorization: Bearer sk_live_..."
```
