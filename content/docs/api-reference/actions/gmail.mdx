## Gmail

Send email and read messages with a service account or OAuth.

---

## Triggers

### New email

Polls the Gmail inbox for new messages once per minute.

**Callable**

```
gmail_new_email_trigger(sender?)
```

**Parameters**

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `sender` | string | No | Filter by sender — exact email, domain (`@example.com`), or wildcard (`*@example.com`) |

**Trigger data**

When the trigger fires, the following fields are available in the workflow environment:

| Field | Type | Description |
| --- | --- | --- |
| `email_id` | string | Gmail message ID |
| `thread_id` | string | Gmail thread ID |
| `from` | string | Sender email address |
| `to` | string | Recipient email address |
| `subject` | string | Email subject line |
| `date` | string | Email date header |
| `body` | string | Plain text body |

## Actions

### List emails
List emails matching filters and return message details.

**Parameters**

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `limit` | number | No | Maximum number of emails to return |
| `q` | string | No | A raw Gmail search query (e.g., 'from:foo@example.com') |
| `unread_only` | boolean | No | If true, only return unread emails |
| `in_inbox` | boolean | No | If true, only return emails in the inbox |

**Response**

```json
[
  {
    "id": "18abc123def456",
    "thread_id": "18abc123def456",
    "message": {
      "subject": "Hello",
      "from": "sender@example.com"
    }
  }
]
```
