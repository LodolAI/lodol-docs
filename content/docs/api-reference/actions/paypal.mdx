## PayPal

Accept payments, manage catalog products, and automate billing with PayPal.

---

## Triggers

### New payment

Polls PayPal for new payment captures once per minute.

**Callable**

```
paypal_new_payment_trigger(status?)
```

**Parameters**

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `status` | string | No | Filter by payment status, e.g. `COMPLETED` |

**Trigger data**

This trigger fires when the event occurs — no additional data is injected into the workflow environment.
