## Google Gemini

Connect Gemini models for generating text or images with Google GenAI.

---

## Actions

### Generate model response
Generate a text response using a Gemini model.

**Parameters**

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `prompt` | string | Yes | The text prompt to send to the model |
| `model` | string | No | The Gemini model to use (defaults to gemini-2.0-flash) |

**Response**

```json
{
  "response_text": "This is a sample generated response."
}
```

---

### Generate image
Generate images from a text prompt using Google's Imagen model.

**Parameters**

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `prompt` | string | Yes | The text prompt describing the image to generate |
| `model` | string | No | The Imagen model to use (defaults to imagen-4.0-generate-001) |

**Response**

```json
{
  "images": [
    "base64encodedimagedata..."
  ],
  "image_count": 1
}
```
