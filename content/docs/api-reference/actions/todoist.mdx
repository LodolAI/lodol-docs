## Todoist

Create and manage Todoist tasks, comments, and projects with API tokens.

---

## Triggers

### New task

Polls Todoist for new tasks once per minute.

**Callable**

```
todoist_new_task_trigger(project_id?, content_pattern?)
```

**Parameters**

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `project_id` | string | No | Todoist project ID to watch; defaults to all projects |
| `content_pattern` | string | No | Filter by task content substring |

**Trigger data**

This trigger fires when the event occurs — no additional data is injected into the workflow environment.

---

## Actions

### Create a task
Create a new Todoist task with optional project and due date

**Parameters**

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `content` | string | Yes | Task content. |
| `project_id` | string | No | Project ID. |
| `due_string` | string | No | Due date string. |

**Response**

```json
{
  "id": "2995104339",
  "content": "Buy milk",
  "project_id": "2203306141",
  "due": {
    "date": "2024-01-20",
    "string": "tomorrow"
  }
}
```

---

### Close a task
Close a Todoist task by ID

**Parameters**

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `task_id` | string | Yes | Task ID to close. |

**Response**

```json
{
  "status": "closed"
}
```

---

### Reopen a task
Reopen a completed Todoist task

**Parameters**

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `task_id` | string | Yes | Task ID to reopen. |

**Response**

```json
{
  "status": "reopened"
}
```

---

### Add a task comment
Add a comment to a Todoist task

**Parameters**

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `task_id` | string | Yes | Task ID to comment on. |
| `content` | string | Yes | Comment text. |

**Response**

```json
{
  "id": "123456789",
  "task_id": "2995104339",
  "content": "Don't forget to get organic milk"
}
```

---

### List projects
Fetch all Todoist projects for the authenticated user

**Response**

```json
[
  {
    "id": "2203306141",
    "name": "Shopping",
    "color": "blue"
  }
]
```
