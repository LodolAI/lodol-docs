## Twitter

Post, reply, delete, like, and search tweets on Twitter using OAuth 2.0.

---

## Triggers

### New mention

Polls Twitter for new mentions of the authenticated account once per minute.

**Callable**

```
twitter_new_mention_trigger(keyword?)
```

**Parameters**

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `keyword` | string | No | Additional keyword to filter mentions |

**Trigger data**

This trigger fires when the event occurs — no additional data is injected into the workflow environment.

---

## Actions

### Post a tweet
Publish a tweet from your connected Twitter account.

**Parameters**

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `text` | string | Yes | Tweet text. |

**Response**

```json
{
  "status": "success",
  "tweet": {
    "id": "1234567890",
    "text": "Just launched our new product!"
  }
}
```

---

### Reply to a tweet
Reply to an existing tweet by ID.

**Parameters**

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `in_reply_to_tweet_id` | string | Yes | Tweet ID to reply to. |
| `text` | string | Yes | Reply text. |

**Response**

```json
{
  "status": "success",
  "tweet": {
    "id": "1234567891",
    "text": "Thanks for sharing!"
  }
}
```

---

### Delete a tweet
Delete a tweet by ID.

**Parameters**

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `tweet_id` | string | Yes | Tweet ID to delete. |

**Response**

```json
{
  "status": "success"
}
```

---

### Like a tweet
Like a tweet on behalf of the authenticated user.

**Parameters**

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `tweet_id` | string | Yes | Tweet ID to like. |

**Response**

```json
{
  "status": "success"
}
```

---

### Search recent tweets
Search recent tweets using a query string.

**Parameters**

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `query` | string | Yes | Search query. |
| `max_results` | number | No | Maximum tweets to return (10-100, defaults to 10). |

**Response**

```json
{
  "status": "success",
  "tweets": [
    {
      "id": "1234567890",
      "text": "Excited about the new AI features! #technology"
    }
  ]
}
```

---

### Get my profile
Get the authenticated user's Twitter profile information.

**Response**

```json
{
  "status": "success",
  "user": {
    "id": "123456789",
    "username": "lodol",
    "name": "Lodol Automation"
  }
}
```
