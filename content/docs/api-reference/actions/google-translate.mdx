## Google Translate

Translate text between languages using Google Cloud Translation API.

---

### Translate text
Translate text from one language to another using Google Translate API.

**Parameters**

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `text` | string | Yes | The text to translate |
| `target_language` | string | Yes | The target language code (e.g., 'en', 'es', 'fr') |
| `source_language` | string | No | The source language code (auto-detected if not provided) |
| `format` | string | No | The format of the source text ('text' or 'html') |
| `model` | string | No | The translation model to use |

**Response**

```json
{
  "translated_text": "Hello, how are you?",
  "detected_source_language": "es",
  "model": "nmt"
}
```
