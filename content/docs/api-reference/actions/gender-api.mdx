## Gender API

Predict gender for names using Gender API.

---

## Actions

### Predict gender by name
Predict the gender associated with a first name, optionally scoped to a country.

**Parameters**

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | Yes | First name to analyze |
| `country` | string | No | ISO 3166-1 alpha-2 country code to localize the prediction |

**Response**

```json
{
  "gender": "male",
  "probability": 0.98,
  "result_found": true,
  "first_name": "John",
  "samples": 12345,
  "duration": "42ms",
  "credits_used": 1,
  "raw_response": {
    "input": {
      "first_name": "John"
    },
    "details": {
      "credits_used": 1,
      "samples": 12345,
      "country": null,
      "first_name_sanitized": "john",
      "duration": "42ms"
    },
    "result_found": true,
    "first_name": "John",
    "probability": 0.98,
    "gender": "male"
  }
}
```

---

### Predict gender by full name
Predict the gender associated with a full name (first and last name combined).

**Parameters**

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `full_name` | string | Yes | Full name to analyze |

**Response**

```json
{
  "gender": "female",
  "probability": 0.95,
  "result_found": true,
  "first_name": "Sandra",
  "last_name": "Miller",
  "samples": 8765,
  "duration": "38ms",
  "credits_used": 1,
  "raw_response": {
    "input": {
      "full_name": "Sandra Miller"
    },
    "details": {
      "credits_used": 1,
      "duration": "38ms",
      "samples": 8765,
      "country": null,
      "first_name_sanitized": "sandra"
    },
    "result_found": true,
    "last_name": "Miller",
    "first_name": "Sandra",
    "probability": 0.95,
    "gender": "female"
  }
}
```
