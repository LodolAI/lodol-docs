## Core

Lodol workflows run on a shared expression engine. This section documents the core building blocks available in every workflow, none of which need integration credentials.

- **Built-in Functions** are pure, stateless functions for text, lists, dates, numbers, and validation.
- **Native Callables** are `api.request` for HTTP calls and `human.*` for human-in-the-loop review tasks.
- **Expressions and Statements** are the AST node types for control flow, variables, and expressions.
