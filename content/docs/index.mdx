## Lodol Developer API

Lodol runs your workflows. The Developer API lets your own software run them too. You can list the workflows in a workspace, start a run, follow it while it works, and stop it, all with an API key and a few lines of code.

Requests are REST over HTTPS with JSON bodies. Everything lives under a single base URL:

```
https://api-prod.lodol.com/api/v1
```

If you work in Python, the [SDK](https://github.com/LodolAI/lodol-python) wraps the same API so you do not have to hand-write requests.

## Get an API key

Open the Lodol dashboard, go to **Settings > API Keys**, and create a key. Give it a name and the scopes your integration needs. The key is shown once, so copy it then. See [Authentication](/docs/guides/authentication) for scopes, plan limits, and rate limits.

## Make your first request

List the workflows in your workspace. The workspace is taken from the key, so there is no account or team ID to pass.

<Tabs items={['cURL', 'Python']}>

```bash tab="cURL"
curl https://api-prod.lodol.com/api/v1/workflows \
  -H "Authorization: Bearer sk_live_..."
```

```python tab="Python"
from lodol import Lodol

client = Lodol(api_key="sk_live_...")

for workflow in client.workflows.list():
    print(workflow.id, workflow.name)
```

</Tabs>

## Run a workflow

Runs are asynchronous. You start one by its workflow ID and get back an execution you can poll.

<Tabs items={['cURL', 'Python']}>

```bash tab="cURL"
curl -X POST \
  https://api-prod.lodol.com/api/v1/workflows/665f1a2b3c4d5e6f7a8b9c0d/run-async \
  -H "Authorization: Bearer sk_live_..."
```

```python tab="Python"
execution = client.workflows.run("665f1a2b3c4d5e6f7a8b9c0d", wait=True)

print(execution.status)   # success, failed, or stopped
```

</Tabs>
