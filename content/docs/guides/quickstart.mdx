## Quickstart

This guide takes you from an API key to a finished run.

### Before you start

You need a Lodol account, a workflow built in the dashboard, and an API key with the `workflows:read`, `workflows:execute`, and `executions:read` scopes.

### 1. Create an API key

In the dashboard, go to **Settings > API Keys** and create a key. Copy it when it is shown, since you cannot see it again. Keep it in an environment variable rather than in your code.

```bash
export LODOL_API_KEY="sk_live_..."
```

The Python SDK reads `LODOL_API_KEY` on its own, so `Lodol()` picks it up with no arguments.

### 2. List your workflows

<Tabs items={['cURL', 'Python']}>

```bash tab="cURL"
curl https://api-prod.lodol.com/api/v1/workflows \
  -H "Authorization: Bearer $LODOL_API_KEY"
```

```python tab="Python"
from lodol import Lodol

client = Lodol()

for workflow in client.workflows.list():
    print(workflow.id, workflow.name)
```

</Tabs>

The response lists the workflows in your workspace:

```json
{
  "workflows": [
    {
      "id": "665f1a2b3c4d5e6f7a8b9c0d",
      "name": "Daily Report Generator",
      "description": "Generates and emails daily sales reports",
      "created_by": "665f1a2b3c4d5e6f7a8b9c0e",
      "created_at": "2026-03-01T10:00:00+00:00",
      "updated_at": "2026-03-10T15:30:00+00:00",
      "last_run_at": "2026-03-17T08:00:00+00:00"
    }
  ]
}
```

### 3. Run a workflow

Use a workflow ID from the previous step to start a run.

<Tabs items={['cURL', 'Python']}>

```bash tab="cURL"
curl -X POST \
  https://api-prod.lodol.com/api/v1/workflows/665f1a2b3c4d5e6f7a8b9c0d/run-async \
  -H "Authorization: Bearer $LODOL_API_KEY" \
  -H "Idempotency-Key: my-first-run"
```

```python tab="Python"
execution = client.workflows.run("665f1a2b3c4d5e6f7a8b9c0d")

print(execution.id, execution.status)
```

</Tabs>

The run is accepted and queued. The response comes back right away with an execution ID and a `queued` status:

```json
{
  "execution_id": "683b2c3d4e5f6a7b8c9d0e1f",
  "workflow_id": "665f1a2b3c4d5e6f7a8b9c0d",
  "status": "queued",
  "created_at": "2026-04-14T10:30:00+00:00"
}
```

### 4. Wait for the result

Poll the execution until it reaches a terminal status: `success`, `failed`, or `stopped`. In Python, `wait()` does the polling for you. Over curl, read the execution and check `status` yourself.

<Tabs items={['cURL', 'Python']}>

```bash tab="cURL"
curl "https://api-prod.lodol.com/api/v1/executions/683b2c3d4e5f6a7b8c9d0e1f?include_step_results=true" \
  -H "Authorization: Bearer $LODOL_API_KEY"
```

```python tab="Python"
execution = client.executions.wait("683b2c3d4e5f6a7b8c9d0e1f", timeout=120)

if execution.status == "success":
    print("done", execution.steps)
else:
    print(execution.status, execution.error)
```

</Tabs>

Add `?include_step_results=true` to see the output of each step:

```json
{
  "execution_id": "683b2c3d4e5f6a7b8c9d0e1f",
  "workflow_id": "665f1a2b3c4d5e6f7a8b9c0d",
  "status": "success",
  "started_at": "2026-04-14T10:30:00+00:00",
  "completed_at": "2026-04-14T10:30:45+00:00",
  "steps": [
    { "index": 0, "status": "completed", "result": "..." },
    { "index": 1, "status": "completed", "result": "..." }
  ],
  "error": null
}
```

You can also start a run and wait in one call:

```python
execution = client.workflows.run("665f1a2b3c4d5e6f7a8b9c0d", wait=True, timeout=120)
```
