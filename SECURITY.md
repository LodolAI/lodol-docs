# Security Policy

## Reporting a Vulnerability

We appreciate your help in identifying security vulnerabilities in the Lodol documentation site. If you discover a security issue, please report it responsibly by emailing **vulnerability@lodol.com** instead of using the public issue tracker.

When reporting a vulnerability, please include:

- A clear description of the issue
- Steps to reproduce the vulnerability (if applicable)
- The affected version(s)
- Any potential impact or exploit scenario
- Your contact information for follow-up

We will acknowledge receipt of your report within 48 hours and work to provide a timeline for a fix. Please allow us reasonable time to address the issue before public disclosure.

## Security Considerations

### Dependencies

This project uses npm dependencies for a Next.js-based documentation site. We regularly:

- Monitor dependencies for known vulnerabilities using npm audit
- Apply security patches and updates promptly
- Keep Node.js and all tooling versions current

### No Sensitive Data

This repository is public and should not contain:

- API keys, tokens, or credentials
- Private configuration
- Sensitive user data

If you discover any sensitive information committed to this repository, please report it immediately to vulnerability@lodol.com.

## Contact

- **Security issues**: vulnerability@lodol.com
- **General inquiries**: support@lodol.com
- **GitHub Issues**: For non-security bugs and feature requests only

Thank you for helping keep Lodol secure.
